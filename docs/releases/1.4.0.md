# MiNotifyWin 1.4.0

- 测试通知跟随桌面提醒和提醒内容：Windows 通知、托盘气泡、仅应用内记录均使用对应行为。
- 支持选择或清除默认配图，消息图片优先；消息与默认图片均无图时不显示配图。设置导入导出一并携带默认图片。
- 删除多余预览说明与图标库提示，精简小字，将设置中的正文解密入口改为「应用密钥」。
- 撤回 KICK 或认证拒绝后强制 300 秒等待；重连严格遵循设置。移除缺失 appId 获取的固定冷却，保留正在获取时的请求合并。
- 移除旧多方案设置迁移、过时的 Python 后台发布处理及测试记录数量限制。
- 将源码、测试、构建脚本、依赖说明和发布材料整理为独立仓库。

已验证：44 项核心检查、5 项原生检查、25 张界面检查截图。配图优先级、无图情况、提醒模式与内容均包含在检查中。

Windows x64 便携 ZIP 内含运行时，解压后运行 MiPushDesk.exe。Windows 横幅和提示音仍受系统通知设置影响。KICK wait/internal-error 的服务端原因尚未通过手机离线对照确认。
